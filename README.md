# 🛠️ Lenny the LaborBot

**Lenny the LaborBot** is a sarcastic, blue-collar-style AI chatbot built with Streamlit and powered by Groq's blazing-fast LLaMA 3 models. Think of him as your neighborhood mechanic — smart, straight-talking, and full of dry humor.

## 🚀 Live Demo

Deployed on [Streamlit Cloud](https://lennythelaborbot.streamlit.app) 

## 🎯 Features

- 🤠 Personality-driven AI: Sarcastic, blunt, and funny
- ⚡ Powered by Groq's `llama3-70b-8192` for fast and accurate replies
- 💬 Simple Streamlit interface with a dark, themed layout
- 🔐 Secure via Streamlit Secrets for API key handling

## 🧰 Tech Stack

- Python 3.9+
- Streamlit
- Groq API (LLaMA 3 model)
- Requests

## 📁 File Structure

```
├── lenny_the_laborbot.py     # Main Streamlit app
├── requirements.txt          # Dependencies
└── .streamlit
    └── secrets.toml          # API credentials
```
